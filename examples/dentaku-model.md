# 電卓ドメインモデル(仮想DSL)

```
# ============================================
# 用語集
# ============================================
用語集 電卓 {
  表示値     : 文字列  "画面に見えている数字列"
  被演算数   : 数値    "確定済みの左辺"
  演算子     : 列挙    { +, -, ×, ÷ }
  精度       : 概念    "10進固定小数。2進浮動小数は使わない"   # ←ビジネス判断
  桁数上限   : 数値    12
}

# ============================================
# 集約: 電卓(ほぼ全体が状態機械)
# ============================================
集約 電卓 {

  # --- 制御状態 ---
  状態: 初期
      | 整数入力中
      | 小数入力中
      | 演算子受付後
      | 結果表示
      | エラー

  # --- 遷移(入力イベント駆動) ---
  遷移 初期        --数字--> 整数入力中
  遷移 整数入力中  --数字--> 整数入力中     [条件: 桁数 < 桁数上限]
  遷移 整数入力中  --数字--> 整数入力中     [条件: 桁数 == 桁数上限, 動作: 無視]
  遷移 整数入力中  --小数点--> 小数入力中
  遷移 小数入力中  --小数点--> 小数入力中   [動作: 無視]   # 2個目の「.」は捨てる
  遷移 *入力中     --演算子--> 演算子受付後 [動作: 左辺確定]
  遷移 演算子受付後 --数字--> 整数入力中    [動作: 右辺入力開始]
  遷移 演算子受付後 --演算子--> 演算子受付後 [動作: 演算子上書き]  # ←仕様判断
  遷移 *入力中     --イコール--> 結果表示   [動作: 評価]
  遷移 結果表示    --数字--> 整数入力中     [動作: 全クリアして新規入力]
  遷移 結果表示    --演算子--> 演算子受付後 [動作: 結果を左辺に]   # 連続計算
  遷移 *           --C--> 初期
  遷移 *           --ゼロ除算検出--> エラー
  遷移 エラー      --C--> 初期
  禁止 エラー --数字--> *        # エラー中はC以外を受け付けない

  # --- 不変条件 ---
  不変条件 {
    表示値の桁数 <= 桁数上限
    表示値に含まれる小数点は高々1個
    状態 == エラー ならば 表示値 == "E"
  }
}

# ============================================
# 評価器: モデルは中身を書かない(契約に縮退)
# ============================================
契約 評価器 {
  入力: (被演算数, 演算子, 右辺)
  出力: 数値 または ゼロ除算失敗

  # 中身のアルゴリズムは書かない。性質だけ宣言する。
  性質 {
    可換性     : a + b == b + a、a × b == b × a
    逆演算     : (a + b) - b == a          (精度の範囲で)
    単位元     : a + 0 == a、a × 1 == a
    十進厳密性 : 0.1 + 0.2 == 0.3          # 2進浮動小数なら破れる。精度宣言の検証
    丸め       : 結果が桁数上限を超えたら「四捨五入して表示」  # ←ビジネス判断
    失敗       : b == 0 かつ 演算子 == ÷ ならば ゼロ除算失敗
                 (例外を投げない。失敗は値として返す)
  }
}

# ============================================
# 性質(検証者エージェントへの攻撃指示)
# ============================================
性質 {
  入力頑健性:
    任意のボタン押下列に対し、クラッシュせず 不変条件 が保たれる
    # ファジング: ランダムなキー列を叩き続ける

  C の完全性:
    どの状態からでも C を押せば 初期 と等価な状態に戻る
    # 「等価」= 以後の任意の入力列に対し挙動が一致すること

  表示の忠実性:
    結果表示 状態の表示値は、評価器の出力の丸め結果と一致する

  網羅性(静的検査):
    全状態 × 全入力種別 に対し遷移が定義済みか「無視」が明示されている
    # 暗黙の未定義遷移を許さない
}

# ============================================
# 依存
# ============================================
文脈間 {
  # 外部依存なし。この宣言自体が「電卓は完全にオフラインで動く」という仕様
}
```
