# すごろくドメインモデル(仮想DSL)

```
# ============================================
# 用語集(ユビキタス言語)
# ============================================
用語集 すごろく {
  プレイヤー   : 実体   "ゲームに参加し、コマを進める者"
  コマ位置     : 数値   範囲(0..ゴールマス)
  マス         : 値     "盤面上の1区画。効果を持ちうる"
  手番         : 概念   "コマンドを発行できる唯一のプレイヤー"
  出目         : 数値   範囲(1..6)  由来: 外部(サイコロ)
  効果         : 概念   "マス到着時に自動発動するルール"
}

# ============================================
# 集約: ゲーム(拡張状態機械)
# ============================================
集約 ゲーム {

  # --- 制御状態(列挙可能な少数の状態) ---
  状態: 募集中 -> 進行中 -> 終了
  遷移 募集中 -> 進行中 [条件: プレイヤー数 >= 2]
  遷移 進行中 -> 終了   [契機: ゴール到達]
  禁止 終了 -> 進行中          # 終わったゲームは再開しない

  # --- データ状態(変数。直積で爆発する部分はこちらに) ---
  変数 {
    プレイヤー位置 : 写像<プレイヤー, コマ位置>
    手番           : プレイヤー
    連鎖深度       : 数値        # カスケード検出用(内部)
  }

  # --- 不変条件(いつでも成り立つこと) ---
  不変条件 {
    全て(p in プレイヤー): 0 <= プレイヤー位置[p] <= ゴールマス
    手番 in プレイヤー
    状態 == 終了 ならば 存在(p): プレイヤー位置[p] == ゴールマス
  }
}

# ============================================
# フロー: 手番の進行
# ============================================
フロー 手番進行 {

  コマンド サイコロを振る (実行者: 手番プレイヤーのみ)   # 権限
    -> イベント 出目確定(出目)

  ポリシー: 出目確定 のとき
    -> コマンド コマを進める(出目)
    -> イベント 到着(マス)

  # 到着イベントは決定表「マス効果」に委譲(下記)
  ポリシー: 到着(マス) のとき -> 決定表 マス効果 を適用

  ポリシー: 効果解決済み のとき
    -> コマンド 手番を渡す
    -> イベント 手番交代

  # --- 連鎖と停止性 ---
  連鎖上限: 3    # 効果の連鎖は3段まで。超過は「効果なし」に縮退
  検査: ポリシー連鎖グラフにループなきこと    # 静的検査
}

# ============================================
# 決定表: マス効果(ルールはデータとして持つ)
# ============================================
決定表 マス効果 {
  入力: 到着マス番号
  出力: アクション

  | 到着マス | アクション            | 備考           |
  |---------|----------------------|----------------|
  | 5       | 移動(-3)             | 3マス戻る      |
  | 10      | 手番スキップ(次回)    | 1回休み        |
  | 15      | 移動(+4)             | ワープ         |
  | 22      | 移動(-3)             | ※7へ戻る→再判定なし(連鎖上限参照) |
  | ゴールマス| ゲーム終了           | 勝者確定       |
  | その他   | 効果なし             |                |

  検査: 移動アクションの適用結果が範囲(0..ゴールマス)に収まること
        # 例: マス2で移動(-3)なら0で止まる(飽和演算)と宣言
  境界規則: 位置は飽和する(0未満は0、ゴール超は跳ね返りなし・ゴール扱い)
}

# ============================================
# 性質(検証者エージェントへの攻撃指示)
# ============================================
性質 {
  停止性:
    任意の出目系列に対し、ゲームは有限手数で 終了 に到達する
    # 反例探索: 検証者が出目系列を生成して攻撃

  公平性:
    手番交代は プレイヤー列の巡回順 に一致する
    (手番スキップ効果による欠番を除く)

  非決定性の閉包:
    出目(1..6)のいかなる値でも 不変条件 は保たれる
    # プロパティベーステスト: 全出目でランダム系列を流す

  履歴再現性:
    イベント列から 変数(プレイヤー位置・手番) が一意に再構成できる
    # イベントソーシングとの同型性の検証
}

# ============================================
# 依存と失敗セマンティクス(最小限の例)
# ============================================
文脈間 {
  依存 効果音サービス (任意, 失敗時: 無音で続行)   # 劣化許容
  依存 対戦記録サービス (任意, 失敗時: ローカル保持して後送)
  # ゲーム進行に「必須」の外部依存は存在しない、という宣言自体が情報
}
```
